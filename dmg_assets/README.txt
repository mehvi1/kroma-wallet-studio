Kroma Wallet Studio · Local development build

1. Drag Kroma.app to Applications.
2. Connect and unlock your iPhone over USB; choose Trust This Computer.
3. Select Scan Wallet, open Wallet on the iPhone, and tap the card you want to identify.
4. Redeem a Kroma activation code to load the private skin library. Choose a built-in look, create your own palette, or import an image. Preview, then choose Apply to this card.

Applying modifies local Wallet artwork using an iOS-version-dependent method. Keep a current iPhone backup. This build does not create a rollback backup and has not been tested on a physical iPhone running iOS 27.0–27.0.1. Do not treat the compatibility probe as a guarantee.

Premium skins require an online Kroma membership service. If this build was not configured with the Kroma API, premium skins remain unavailable. This local build is ad-hoc signed and is not notarized for public distribution.
